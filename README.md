# Amazon

This project is a simple e-commerce website inspired by Amazon. It allows users to browse products, add items to their cart, choose delivery options, and view their order summary.

## Features

- Browse and view products
- Add and remove products from the cart
- Update product quantities
- Select delivery options
- View cart and order summary
- Calculate product, shipping, and total costs
- Responsive layout
- JavaScript unit testing with Jasmine

## Technologies Used

- HTML
- CSS
- JavaScript
- DayJS 
- Jasmine
- Promise
- Object Oriented Programming system (OOPS)

## Getting Started

Clone the repository:

git clone https://github.com/Samrdhi-SinGh/amazon-project.git
cd amazon-project

Open amazon.html in your browser to run the project.
